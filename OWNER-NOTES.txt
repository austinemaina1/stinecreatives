# stinecreatives website
- Edit all text, services, projects and contact details in `js/data.js`.
- Add a project: copy a block in PROJECTS, add screenshots to `assets/img/`, set `image`.
- Email delivery: create a free Formspree form, paste its URL into `formEndpoint`.
- Host free on Netlify, Vercel or GitHub Pages (upload this folder as is).
- Private visitor counter: create a free account at goatcounter.com, choose a site code, then paste that code into `goatCounter` in `js/data.js`. Only you can see the numbers when you log in (keep "Allow public access" switched off in its settings).
- Quick-help chat answers are in `CHAT` at the bottom of `js/data.js`.
- Private notes for the site owner. Do NOT upload this file to GitHub or Netlify; upload only the "site" folder.
- Edit text, services, projects and contact details in site/js/data.js. Headings and buttons are in site/js/app.js.
- Whatsapp number and email are at the top of data.js (SITE block). formEndpoint = Formspree URL, goatCounter = GoatCounter code.
- SEO: each page has its text baked into the HTML so Google can read it. If you change wording in data.js/app.js, visitors see the new text straight away, but the baked-in copy only updates when it is regenerated (ask Claude to rebuild it).
- Case studies now have their own pages: case-aura-hotel.html, case-gbs-suppliers.html, case-apartment-tracker.html. When you add a project, a new case-<slug>.html page is needed too (copy an existing one and change data-p to the new slug).
- sitemap.xml lists every page. Add a new <url> line when you add a page.
- When copying files from a new zip to your repo, do NOT overwrite js/data.js if you added your GoatCounter code there.
